ArnaLead — собственная реализация только ручной двухсторонней передачи. От OrtaInbox отличается основным механизмом: здесь смена владельца требует явного принятия получателем; нет одобрения текста другим администратором. Общий оригинальный HTTP/SQLite/UI код StartupLab переиспользован, предметные правила написаны отдельно. Бренд, графика и закрытый код референса не копировались.
